本文说明项目从容器启动、HTTP 请求进入、权限校验、应用服务、LangGraph 工作流、节点执行到基础设施访问的完整调用链。

## 1. 总体运行拓扑

```text
Browser
  |
  v
Frontend Nginx (:8080)
  |
  v
FastAPI Backend (:8000)
  |-- MySQL          事实数据、权限、审计、任务
  |-- Redis          FAQ 缓存、权限版本
  |-- MinIO          原文件、Markdown、图片
  |-- Milvus         Dense Vector、BM25、稀疏向量
  |-- BGE-M3         本地 Embedding
  |-- LLM/VLM/Rerank 外部 OpenAI 兼容服务
  |
MySQL background_job
  |
  v

```

Compose 启动顺序：

```text
mysql / redis / minio / milvus / etcd
  -> minio-init / db-init
  -> seed
  -> backend / worker
  -> frontend
```

- db-init 顺序执行 backend/migrations/*.sql。
- seed 执行 bootstrap/seed.py。
- sample_data.py 写入完整演示数据。

## 2. 后端启动框架

### 2.1 Uvicorn 入口

文件：backend/kb_manage_platform/main.py

- app：从 api.app 导入 FastAPI 实例。
- __main__：读取 Settings.runtime_options() 并调用 uvicorn.run()。

### 2.2 FastAPI 应用入口

文件：backend/kb_manage_platform/api/app.py

函数：ApplicationFactory.create()

步骤：

1. get_settings() 读取 backend/.env。
2. 定义 lifespan()。
3. lifespan() 调用 build_container(settings)。
4. 将容器保存到 app.state.container。
5. 注册 CORS。
6. app.include_router(api_router, prefix="/api/v1")。
7. 注册 request_id_middleware。
8. 注册统一异常处理器。
9. 应用关闭时调用 container.close()。

### 2.3 路由总装配

文件：backend/kb_manage_platform/api/router.py

依次 include：

- health
- auth
- audit
- departments
- users
- roles
- knowledge
- knowledge-categories
- system configuration
- query
- import
- faq-gap
- dashboard

### 2.4 组合根

文件：backend/kb_manage_platform/bootstrap/container.py

函数：build_container(settings)

负责创建并注入：

- Database、Redis
- MysqlAuditLogger、Mysql*Repository
- MinioObjectStorage
- ModelEmbedder
- MilvusStore、MilvusVectorIndex
- MineruDocumentParser
- VlmImageSummarizer
- ModelReranker
- LangChainHydeGenerator、LangChainAnswerGenerator
- KBQueryWorkflow
- KBImportWorkflow
- KnowledgeMaintenanceWorkflow
- FaqGapWorkflow
- 各 Application Service

具体实现只在组合根创建，其他层依赖 domain/ports.py 中的 Protocol。

## 3. 通用 HTTP 请求框架

```text
Browser
  -> /api/v1/...
  -> FastAPI request_id_middleware
  -> api/router.py 匹配路由
  -> api/routes/<module>.py 路由函数
  -> api/dependencies.py 校验 JWT 和权限
  -> Pydantic Schema 校验参数
  -> Application Service
  -> LangGraph Workflow 或 Repository Port
  -> Infrastructure Adapter
  -> MySQL / Redis / MinIO / Milvus / 外部模型
  -> 路由函数组装 Response
  -> 统一异常处理
```

认证依赖链：

```text
require_permission(permission_code)
  -> checker()
  -> get_current_user()
  -> AuthService.authenticate()
  -> JwtTokenService.parse()
  -> MysqlIdentityRepository.get_user_context()
  -> 校验 user.is_active 和 permission_version
  -> 校验 permission_code
```

异常映射位于 api/app.py：

- AppError -> 对应业务错误。
- RequestValidationError -> 422。
- PermissionError -> 403。
- LookupError -> 404。
- ValueError -> 422。
- IntegrityError -> 409。
- SQLAlchemyError -> 503。

## 4. 前端运行框架

### 4.1 启动

文件：frontend/src/main.tsx

```text
main.tsx
  -> ConfigProvider
  -> BrowserRouter
  -> AuthProvider
  -> AppRoutes
```

### 4.2 路由保护

文件：

- frontend/src/App.tsx
- frontend/src/components/AppLayout.tsx
- frontend/src/components/Guards.tsx

流程：

1. ProtectedRoute 判断当前用户。
2. PermissionRoute 判断页面权限。
3. AppLayout 渲染菜单和内容区。
4. Outlet 渲染当前页面。

### 4.3 普通 API

文件：frontend/src/api/client.ts

函数：request<T>()

1. 读取内存 accessToken。
2. 设置 Authorization: Bearer。
3. fetch("/api/v1" + path)。
4. 401 时派发 auth:unauthorized。
5. 失败时 parseError()。
6. 成功时解析 JSON。

### 4.4 SSE

文件：frontend/src/api/sse.ts

函数：streamQuery()

1. POST /api/v1/query/stream。
2. 读取 response.body.getReader()。
3. 按空行拆分 SSE block。
4. 解析 event 和 data。
5. 回调 ChatPage。

## 5. 登录流程

```text
LoginPage 提交表单
  -> frontend/src/pages/LoginPage.tsx
  -> AuthContext.login()
  -> authApi.login()
  -> api/client.ts request()
  -> POST /api/v1/auth/login
  -> api/routes/auth.py login()
  -> AuthService.login()
  -> MysqlAccountRepository.get_by_username()
  -> ScryptPasswordHasher.verify()
  -> MysqlAccountRepository.record_login_failure()
     或 clear_login_failures()
  -> MysqlIdentityRepository.get_user_context()
  -> JwtTokenService.issue()
  -> MysqlAuditLogger.record("auth.login")
  -> TokenResponse
  -> AuthContext 保存 accessToken 和 user
```

失败路径：

- 用户名不存在：AuthenticationError。
- 账号停用：AuthorizationError。
- 锁定中：AuthenticationError。
- 密码错误：累计失败次数，达到阈值后写入 locked_until。

### 12.1 前端



```text

  -> 生成 request_id
  -> session_id 为空时生成 UUID
  -> MysqlIdentityRepository.get_user_context()
  -> MysqlConversationRepository.get_recent_messages()
  -> KBQueryWorkflow.ainvoke()
```

### 12.4 LangGraph

```text
node_entry
  -> node_faq_cache
     -> FAQ 命中：node_answer_output
     -> FAQ 未命中：并行 node_search_embedding + node_search_hyde
  -> node_rrf
  -> node_auth_pre
  -> node_rerank
  -> node_auth_final
  -> node_answer_output
  -> node_audit
```

### 12.5 节点调用表

| 节点 | 文件 | 调用目标 |
| --- | --- | --- |
| NodeQueryEntry | node_query_entry.py | 校验用户 active、问题非空 |
| NodeFaqCache | node_faq_cache.py | RedisFaqCache.lookup() |
| NodeSearchEmbedding | node_search_embedding.py | MilvusHybridRetriever.retrieve() |
| NodeSearchHyde | node_search_hyde.py | LangChainHydeGenerator.generate() + MilvusVectorRetriever.retrieve() |

| NodeAuthFilter | node_auth_filter.py | MysqlAuthorizationEngine.filter_allowed() |
| NodeRerank | node_rerank.py | ModelReranker.rerank() |
| NodeAnswerOutput | node_answer_output.py | FAQ 直答或 LangChainAnswerGenerator.generate() |

### 12.6 检索底层

```text
MilvusHybridRetriever.retrieve()
  -> ModelEmbedder.embed()
  -> MilvusStore.hybrid_search()
     -> Dense Vector
     -> BM25 Sparse Vector
     -> RRF
```

### 12.7 FAQ 快答

```text
RedisFaqCache.lookup()
  -> Redis get()
  -> 未命中时 MysqlFaqRepository.lookup()
  -> normalized_hash 精确匹配
  -> FAQ PermissionPolicy.matches()
  -> Redis set()
```

### 12.8 SSE 输出

```text

  -> query_stream.event_stream()

  -> delta
  -> citation
  -> usage
```

