## 2. 全局约束摘要

- 认证方式：Bearer JWT，默认有效期 8 小时。
- 权限模型：操作权限 RBAC + 知识四维数据权限。
- 四维权限：global、department、role、user，按 OR 逻辑组合。
- API 前缀：`/api/v1`。
- 后端分层：API / Service / Domain / Infrastructure / Bootstrap。
- 事实存储：MySQL、Redis、MinIO、Milvus。
- 本地向量模型：BGE-M3，默认 CPU，FP16=False。
- 所有知识访问必须实时执行数据权限校验。
- 密码、Token 和模型密钥不得写入日志。
- 固定示例数据必须使用稳定 ID，并支持幂等执行。

## 3. 模块需求

### 目标
建立可信用户身份，签发访问令牌，处理首次改密、退出和会话失效。

### 页面

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 登录页 | /login | 用户名密码登录、错误提示 |
| 修改密码页 | /change-password | 修改当前用户密码 |

### 功能需求

| 编号 | 需求 |
| --- | --- |
| AUTH-F01 | 本地账号登录并返回 Token 和用户权限 |
| AUTH-F02 | 登录失败累计次数，达到阈值后锁定 |
| AUTH-F03 | 查询当前登录用户资料 |
| AUTH-F04 | 退出登录并清除前端 Token |
| AUTH-F05 | 修改自己的密码，校验旧密码和复杂度 |
| AUTH-F06 | Token 与权限版本绑定，权限变更后强制失效 |

### API

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | /api/v1/auth/login | 公开 | 登录 |
| GET | /api/v1/auth/me | 登录用户 | 当前用户 |
| POST | /api/v1/auth/logout | 登录用户 | 退出 |
| POST | /api/v1/auth/change-password | 登录用户 | 修改密码 |

### 数据与审计
- iam_user.password_hash
- iam_user.failed_login_attempts
- iam_user.locked_until
- iam_user.permission_version
- qa_audit：登录成功、登录失败、改密

### 验收标准
- 未登录访问业务页面跳转 /login。
- 错误密码不会泄露账号是否存在。
- 权限或角色变化后重新登录才能获得新权限。
- 连续失败达到阈值后正确锁定。
- 修改密码后旧密码不可再登录。
