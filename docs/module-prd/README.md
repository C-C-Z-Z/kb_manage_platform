## 公共规则

- API 统一前缀：`/api/v1`
- 认证：Bearer JWT
- 操作权限：RBAC
- 知识权限：四维 OR 权限
- 本地向量模型：BGE-M3（CPU）
- 数据存储：MySQL + Redis + MinIO + Milvus

## 维护要求

1. 新增模块时，新增独立 PRD 并更新本索引。
2. 接口、状态机、权限码或数据表变化时，同步修改对应模块 PRD。
3. 模块验收标准应保持可测试、可量化，避免仅写“正常工作”。
