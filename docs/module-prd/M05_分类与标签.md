## 2. 全局约束摘要

- 认证方式：Bearer JWT，默认有效期 8 小时。
- 权限模型：操作权限 RBAC + 知识四维数据权限。
- 四维权限：global、department、role、user，按 OR 逻辑组合。
- API 前缀：`/api/v1`。
- 后端分层：API / Service / Domain / Infrastructure / Bootstrap。
- 事实存储：MySQL、Redis、MinIO、Milvus。
- 本地向量模型：BGE-M3，默认 CPU，FP16=False。
- 所有知识访问必须实时执行数据权限校验。
- 密码、Token 和模型密钥不得写入日志。
- 固定示例数据必须使用稳定 ID，并支持幂等执行。

## 3. 模块需求

### 目标
维护知识分类字典和知识标签，支持台账筛选。

### 页面
- 知识台账中的“分类管理”弹窗。
- 知识详情中的分类和标签编辑。
- 知识列表中的分类筛选。

### 功能需求
- 分类新增、编辑、停用、删除和排序。
- 分类被知识引用时禁止删除。
- 知识可关联一个分类和多个标签。
- 分类下拉仅展示 active 分类。

### API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/v1/knowledge-categories | 分类列表 |
| POST | /api/v1/knowledge-categories | 新增分类 |
| PATCH | /api/v1/knowledge-categories/{category_id} | 编辑分类 |
| DELETE | /api/v1/knowledge-categories/{category_id} | 删除未引用分类 |

### 数据表
- knowledge_category
- knowledge_unit.category_id
- knowledge_unit.tags

### 验收标准
- 新增分类后可在新建知识下拉中选择。
- 删除被引用分类时返回冲突错误。
- 标签支持录入和展示。
