## 2. 全局约束摘要

- 认证方式：Bearer JWT，默认有效期 8 小时。
- 权限模型：操作权限 RBAC + 知识四维数据权限。
- 四维权限：global、department、role、user，按 OR 逻辑组合。
- API 前缀：`/api/v1`。
- 后端分层：API / Service / Domain / Infrastructure / Bootstrap。
- 事实存储：MySQL、Redis、MinIO、Milvus。
- 本地向量模型：BGE-M3，默认 CPU，FP16=False。
- 所有知识访问必须实时执行数据权限校验。
- 密码、Token 和模型密钥不得写入日志。
- 固定示例数据必须使用稳定 ID，并支持幂等执行。

## 3. 模块需求

### 目标
提供知识规范 Markdown、切片、版本时间线、回滚、预览和原文件下载。

### 页面
- /knowledge/:knowledgeId

### 功能需求
- 查看基础信息、当前版本和标签。
- 查看历史版本、创建人、状态和错误。
- 预览指定版本的 Markdown。
- 查看 Milvus 中的切片列表。
- 已索引历史版本可回滚为当前检索版本。
- 预览实时校验数据权限。
- 原文件下载使用独立操作权限。
- 删除知识同步清理对象、数据库、权限和向量。

### API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/v1/knowledge/{knowledge_id}/versions | 版本历史 |
| POST | /api/v1/knowledge/{knowledge_id}/versions | 创建版本 |
| POST | /api/v1/knowledge/{knowledge_id}/versions/upload | 上传新版本 |
| POST | /api/v1/knowledge/{knowledge_id}/versions/{version_id}/rollback | 版本回滚 |
| GET | /api/v1/knowledge/{knowledge_id}/preview | Markdown + 切片预览 |
| GET | /api/v1/knowledge/{knowledge_id}/download | 下载原文件 |
| DELETE | /api/v1/knowledge/{knowledge_id} | 删除知识 |

### 验收标准
- 预览中文正常。
- 切换版本后预览内容对应版本。
- 回滚只允许 indexed 历史版本。
- 无 knowledge:download 时下载接口拒绝。
- 删除后原预览和下载链接失效。
