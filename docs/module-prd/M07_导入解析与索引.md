## 2. 全局约束摘要

- 认证方式：Bearer JWT，默认有效期 8 小时。
- 权限模型：操作权限 RBAC + 知识四维数据权限。
- 四维权限：global、department、role、user，按 OR 逻辑组合。
- API 前缀：`/api/v1`。
- 后端分层：API / Service / Domain / Infrastructure / Bootstrap。
- 事实存储：MySQL、Redis、MinIO、Milvus。
- 本地向量模型：BGE-M3，默认 CPU，FP16=False。
- 所有知识访问必须实时执行数据权限校验。
- 密码、Token 和模型密钥不得写入日志。
- 固定示例数据必须使用稳定 ID，并支持幂等执行。

## 3. 模块需求

### 目标
将 PDF、DOC/DOCX、Markdown、TXT 转换为规范 Markdown，并完成图片摘要、切片、向量化和 Milvus 索引。

### 页面
- /import
- 知识台账中的“导入”弹窗

### 流程
```
上传文件 -> MinIO 原始桶 -> background_job
-> MinerU/文本解析 -> Markdown 桶
-> 图片摘要 -> 切片 -> BGE-M3 向量
-> Milvus 写入 -> 版本 indexed
```

### 功能需求
- 单文件和批量文件上传。
- 显示等待、解析、切片、向量化、索引、成功、失败状态。
- 失败任务支持单独重试。
- 原始文件、Markdown 和图片资源独立保存。
- 支持文件大小限制。
- 更新版本不能直接破坏已发布版本。

### API

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | /api/v1/import | import:create | 已上传对象创建任务 |
| POST | /api/v1/import/files | import:create | 上传并创建任务 |
| GET | /api/v1/import/jobs/{job_id} | import:read | 查询进度 |
| POST | /api/v1/import/jobs/{job_id}/retry | import:create | 重试失败任务 |
| POST | /api/v1/knowledge/{knowledge_id}/versions/upload | knowledge:update | 知识版本上传 |

### 任务阶段
- queued
- parsing
- summarizing
- chunking
- embedding
- indexing
- completed
- failed

### 验收标准
- 上传成功后生成任务 ID。
- 进度可轮询。
- 失败原因可见并可重试。
- 解析失败时保留原文件，不产生可检索版本。
- 索引成功后当前版本切换正确。

### 当前实现对照
已实现 MinerU 解析、VLM 图片摘要、基础 Markdown 切片、BGE-M3 向量化、Milvus 写入、任务重试和进度轮询。文件夹拖拽、文件哈希去重和完整语义切片属于后续增强。
