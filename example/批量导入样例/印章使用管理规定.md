# 印章使用管理规定

- 制度编号：ADM-SEAL-2026-05
- 发布部门：行政管理部
- 生效日期：2026-05-01
- 数据权限：全局公开

## 一、印章种类

公司印章分为五类：公章、合同专用章、财务专用章、法人名章、发票专用章。各类印章的适用范围互不替代。

## 二、保管责任

1. 公章、法人名章由行政部专人保管，存放于保险柜。
2. 合同专用章由法务部保管。
3. 财务专用章与发票专用章由财务部保管。
4. 印章保管人变更时需办理书面交接手续。

## 三、用印审批

| 文件类型 | 审批要求 |
| --- | --- |
| 常规证明、介绍信 | 部门负责人审批 |
| 对外合同 | 部门负责人 + 法务部审批 |
| 对外担保、授权委托 | 总经理审批 |
| 政府申报材料 | 部门负责人 + 行政部负责人审批 |

## 四、用印流程

1. 申请人填写《用印申请单》，注明文件名称、份数、用途和接收方。
2. 按审批要求完成线上审批。
3. 携带纸质文件与审批记录到印章保管处用印。
4. 保管人核对无误后加盖印章，并在《用印登记簿》登记。

## 五、禁止事项

1. 严禁在空白纸张、空白合同上盖章。
2. 严禁将印章带出办公场所，确有需要的须经总经理书面批准并双人同行。
3. 严禁私自复制、扫描印章。
4. 严禁先用印后补审批手续。

## 六、违规处理

违反本规定造成公司损失的，视情节给予通报批评、经济处罚或解除劳动合同；涉嫌违法的移交司法机关处理。

## 七、常见问题

- **问：电子印章能否替代实体印章？**
  经法务部与行政管理部共同审批后可启用电子印章，适用范围与实体印章一致，需保留完整的用印日志。

- **问：紧急情况下无法完成审批怎么处理？**
  可电话取得审批人同意后先行用印，并在 1 个工作日内补齐书面审批手续。
